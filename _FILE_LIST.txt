❓ COMMON QUESTIONS

Q: Do I need to edit docker-compose.yml?
A: No, only .env.example (copy to .env and update values)

Q: What about SSL certificates?
A: Automatic via Let's Encrypt + Certbot. setup.sh handles it.

Q: Is Redis exposed to the internet?
A: No. Internal Docker network only. Clients access via Nginx proxy.

Q: Can I skip setup.sh and deploy manually?
A: Yes, see DEPLOYMENT-CHECKLIST.md § "Manual Setup"

Q: What's different from Railway dev version?
A: Redis host, Vector DB included, SSL control, self-hosted infrastructure

Q: Where do I put these files?
A: VPS directory: /opt/kasyaf-console/ (or anywhere, but cd into it first)

Q: Do I need to install Docker first?
A: No. setup.sh does it automatically.

Solution: Check logs: docker-compose logs -f
